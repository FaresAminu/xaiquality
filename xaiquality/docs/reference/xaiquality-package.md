# xaiquality: Statistical Quality Audits for Explainable Artificial Intelligence

The xaiquality package provides model-agnostic audits of local
explanations. It combines reference-based contributions, bootstrap
uncertainty, prediction-preserving stability, local fidelity, and a
transparent reliability decision.

## Details

The package implements the Trustworthy Explanation Envelope (TEE) as an
operational diagnostic. A `reliable` result is not a causal claim, a
fairness guarantee, or a clinical certification.
